# Review Log — `write-tests`

**Skill owner:** Alfaisal
**Reviewer:** Greta

## What the reviewer tried

Greta tested the Skill using a JUnit request for a simple Java `square` method.

## What the reviewer found

The generated tests were strong and covered normal, edge, and overflow cases.

However, the response did not fully follow the required output format. It included the test code and useful notes, but it did not provide a clear short summary or a separate explanation of what each individual test checked.

Greta suggested making the output-format instructions more explicit by using fixed headings.

## What changed

I updated the Skill so that every response must use four fixed sections:

1. Summary
2. Test Code
3. What Each Test Checks
4. Assumptions and Missing Information

This makes the expected output structure clearer and more consistent.

## Disagreements

None. I agreed with the reviewer’s feedback and applied the suggested change.
